Stack-Based Navigation Concept (LIFO: Last-In, First-Out)

In a web browser, navigation history is maintained using a Stack data structure. When you visit a new website, your current URL is pushed onto the history stack. When you click the Back button, the previous page is retrieved from the top of the stack and popped off, restoring your last viewed page.

DSA Concept & Algorithm Explanation

1. How Backtracking Works with C++ std::stack

A stack is a LIFO (Last-In, First-Out) container. In browser navigation, each visit to a new page preserves the past:

Step 1
visitPage(url): If a page is already active, push it onto history stack (history.push(currentPage)). Then set currentPage = url. [Time: O(1)]
Step 2
goBack(): If history.empty() is false, retrieve the most recent page with history.top() and remove it with history.pop(). Set currentPage to this restored URL. [Time: O(1)]
Step 3
showHistory(): Clones the stack (std::stack<std::string> temp = history;) and repeatedly reads temp.top() and temp.pop() into a vector. The original stack is completely preserved! [Time: O(N)]
Step 4
clearHistory(): Empties the stack in a while-loop and clears currentPage. [Time: O(N)]

2. Key Viva Questions & Rapid Answers

Q: Why Stack and not Queue?

Backtracking requires returning to the most recent item first (LIFO). A Queue is FIFO (First In, First Out), which would navigate to the oldest page first.

Q: How do real browsers handle Forward?

Real browsers use two stacks: a Back Stack and a Forward Stack. Clicking Back pushes onto Forward Stack; clicking a new link clears Forward Stack.

Q: What is Stack Underflow?

Attempting to pop or read the top of an empty stack. In our C++ code, we prevent underflow by checking if (history.empty()).

Q: What are the complexities?

Time Complexity: O(1) for push, pop, top. Space Complexity: O(N) where N is the number of visited URLs stored.
